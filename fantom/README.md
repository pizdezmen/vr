# Fantom: прототип боя с фантомом

Тренировочное измерение мечника для Meta Quest 3 (WebXR, Immersive Web SDK).
Полностью виртуальная сцена, без смешанной реальности.

## Как играть

- В левой руке щит, в правой меч.
- Фантом замахивается: его клинок раскаляется до оранжевого и звучит нарастающий тон.
- Подставь щит под удар (сверху, слева или справа). Можно и отбить мечом.
- После блока фантом мерцает белым: в этот момент бей его мечом.
- Фантом рассыпается на синие пиксели от места попадания.
- На табло: время реакции на удар, среднее и лучшее, время ответного удара.
- С каждым фантомом подряд замах становится короче. Пропустил удар: скорость сбрасывается.

## Запуск на компьютере

```sh
npm install
npm run dev:runtime
```

Потом в браузере шлема открыть адрес `https://<адрес компьютера>:8082`
(компьютер и шлем в одной сети Wi-Fi), согласиться с предупреждением о сертификате
и нажать Start.

## Где что лежит

- `src/fight.js`: правила боя, меч, щит, табло. В начале файла настройки ощущений.
- `src/phantom.js`: фантом из кубиков, позы ударов, сборка и рассыпание.
- `src/arena.js`: окружение. `src/sound.js`: звуки.
