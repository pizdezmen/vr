# Fantom: бой с фантомом (Unity, Meta Quest 3)

Первый этап игры: тренировочное измерение мечника. Полностью виртуальная сцена.
Unity 6.6 (6000.6.9f1), URP, Meta XR Core SDK, OpenXR, Vulkan.

## Как играть

- В левой руке щит, в правой меч. Курок на любом контроллере начинает забег (3 минуты).
- Фантом замахивается: клинок раскаляется до оранжевого и звучит нарастающий тон.
- Подставь щит под удар или отбей его мечом (парирование даёт больше очков).
- Любое попадание мечом рассыпает фантома на пиксели от места удара.
- Больше очков дают: широкий быстрый взмах, попадание в светящееся ядро на груди,
  ответный удар сразу после блока и серия без пропущенных ударов (множитель до ×3).
- Пока забег не идёт, правый стик вверх и вниз меняет наклон клинка; он запоминается.

## Сборка для шлема

В Unity: меню **Fantom → 2. Собрать игру для шлема (APK)**. Файл появится в `Builds/Fantom.apk`.

Из командной строки:

```
"C:\Program Files\Unity\Hub\Editor\6000.6.9f1\Editor\Unity.exe" -batchmode -nographics -projectPath . -buildTarget Android -executeMethod Fantom.EditorTools.FantomBuild.BuildApk -logFile Logs\build.log
```

Меню **Fantom → 3. Сделать снимки для проверки вида** сохраняет картинки фантома и арены в папку `Preview/`.

## Где что лежит

- `Assets/Game/Scripts/Tuning.cs`: все настройки ощущений и очков в одном месте.
- `Assets/Game/Scripts/FightGame.cs`: правила боя, меч, щит, забег и очки.
- `Assets/Game/Scripts/Phantom.cs`: форма фантома из кубиков, позы ударов, сборка и распад.
- `Assets/Game/Scripts/Arena.cs`, `Board.cs`, `SoundBank.cs`: окружение, табло, звуки.
- `Assets/Resources/Shaders/`: шейдеры. Фантом рисуется одной отрисовкой, распад считает видеокарта.
- `Assets/Game/Editor/`: настройка проекта, сборка и снимки.
